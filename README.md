# hotel_reservation_app

[![CI](https://github.com/ywden/TMA3084_G02_106693_Hotel_Reservation_App/actions/workflows/ci.yml/badge.svg)](https://github.com/ywden/TMA3084_G02_106693_Hotel_Reservation_App/actions/workflows/ci.yml)

Flutter hotel booking prototype for TMA3084 Lab 06 (Lesson 08), Group 02.

## Features
- Booking form with validation (name, phone, check-in date, hotel policy)
- Room list with expandable panels
- Unit and widget tests with a 60% coverage gate in CI

## Run
    flutter pub get
    flutter run

## Test
    flutter analyze
    flutter test --coverage
